# موقع متجر الأثاث الفاخر — Flask + SQLite

موقع متكامل لمتجر أثاث يتضمن:
- صفحة رئيسية جذابة تعرض المنتجات المميزة والعروض والصور ومقاطع الفيديو
- صفحة منتجات مع فلترة حسب التصنيف
- صفحة تواصل تحتوي على نموذج رسائل + زر واتساب مرتبط بالرقم **0927569139**
- زر واتساب عائم يظهر في كل صفحات الموقع
- لوحة تحكم كاملة للمالك لإدارة:
  - المنتجات (إضافة / تعديل / حذف / تمييز كمنتج مميز)
  - العروض والخصومات
  - الصور ومقاطع الفيديو (معرض الصور بالرئيسية)
  - رسائل العملاء الواردة من نموذج التواصل
  - إعدادات الموقع (اسم المتجر، الشعار، رقم الهاتف، رقم واتساب، النبذة التعريفية)
  - تغيير كلمة مرور المالك

تم استخدام الصورة المرفقة (الوسائد المخملية) كشعار افتراضي للموقع، ويمكن استبدالها لاحقًا من لوحة التحكم.

## التشغيل محليًا

```bash
# 1) إنشاء بيئة افتراضية (اختياري لكن يُنصح به)
python3 -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate

# 2) تثبيت المتطلبات
pip install -r requirements.txt

# 3) إنشاء قاعدة البيانات وبيانات تجريبية + حساب المالك
python init_db.py

# 4) تشغيل الموقع
python app.py
```

بعد التشغيل، افتح المتصفح على: `http://127.0.0.1:5000`

## الدخول إلى لوحة التحكم

الرابط: `http://127.0.0.1:5000/admin/login`

بيانات الدخول الافتراضية (غيّرها فورًا من صفحة الإعدادات → تغيير كلمة المرور):
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `Liwan@2026`

## تعديل رقم واتساب

من لوحة التحكم → الإعدادات العامة → حقل "رقم واتساب"، يُكتب بالصيغة الدولية بدون علامة + وبدون الصفر الأول.
مثال: الرقم الليبي `0927569139` يصبح `218927569139` (218 هو مفتاح ليبيا الدولي).
هذا الرقم هو نفسه الذي أُدخل افتراضيًا في المشروع.

## هيكل المشروع

```
furniture_store/
├── app.py              # التطبيق الرئيسي وكل المسارات (Routes)
├── db.py                # الاتصال بقاعدة بيانات SQLite وهيكل الجداول
├── init_db.py            # إنشاء قاعدة البيانات + بيانات تجريبية + حساب المالك
├── requirements.txt
├── static/
│   ├── css/style.css     # تصميم الموقع العام
│   ├── css/admin.css     # تصميم لوحة التحكم
│   ├── images/logo.jpg   # الشعار الافتراضي (الصورة المرفقة)
│   └── uploads/          # الصور والفيديوهات التي تُرفع من لوحة التحكم
└── templates/
    ├── base.html, index.html, products.html, contact.html
    └── admin/            # قوالب لوحة التحكم
```

## ملاحظات مهمة قبل النشر الفعلي

1. غيّر قيمة `SECRET_KEY` في `app.py` إلى مفتاح عشوائي قوي (أو ضعه في متغير بيئة `SECRET_KEY`).
2. غيّر كلمة مرور المالك فور أول تسجيل دخول.
3. عطّل وضع `debug=True` في نهاية `app.py` عند النشر على خادم حقيقي، واستخدم خادم إنتاجي مثل `gunicorn`.
4. تأكد من عمل نسخة احتياطية دورية لملف قاعدة البيانات `store.db` ومجلد `static/uploads`.
